# shopify-runtime

Metadata Marketplace App for products, customers, and orders.

- **App id:** `shopify-runtime`
- **Version:** see `manifest.yaml`
- **Hosting:** `runtime`
- **Execution:** generic HTTP tools against a workspace Shopify connection

There is no Shopify SDK in this package. See the collection
[README](../../README.md) for staff vs customer tools, Hub email OTP, and
ownership checks.
